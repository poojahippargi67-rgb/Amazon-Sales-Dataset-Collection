# Amazon Sales Dataset Collection

## Objective

To collect and organize an Amazon product dataset for data analytics.

## Dataset Description

The dataset contains Amazon product information, including product names, categories, actual prices, discounted prices, ratings, and rating counts.

## Dataset Source

Kaggle – Amazon Sales Dataset

## File

`amazon.csv`

## Tools Used

* Kaggle
* CSV
* GitHub

## Purpose

This dataset can be used for data cleaning, exploratory data analysis (EDA), product rating analysis, and discount analysis.

## Expected Outcome

A collected and organized dataset ready for further data analytics.
